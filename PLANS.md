# ExecPlans

Usar un ExecPlan cuando un milestone afecte múltiples componentes, la implementación requiera varias fases, exista incertidumbre técnica relevante, la tarea previsiblemente ocupe varias sesiones o el usuario pida explícitamente un plan.

Los ExecPlans son documentos vivos: deben actualizarse a medida que cambia el conocimiento real del repositorio. Cada plan debe registrar:

- objetivo;
- estado inicial;
- decisiones;
- progreso;
- descubrimientos;
- tests;
- riesgos;
- acceptance criteria.

No usar un plan para ampliar el scope autorizado ni para sustituir un ADR cuando se cambie o concrete una decisión arquitectónica significativa.
