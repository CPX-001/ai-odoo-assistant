## Environment reconciliation and runner repair

environment supplied pytest; Playwright 1.55.0 was installed only as an untracked local test
dependency and was not added to the product dependency graph.

The existing P5.6 real-browser runner initially timed out on an English Odoo user because it located
the launcher, history and submit controls by Spanish accessible names. The runner now uses stable
Assistant CSS hooks for those controls and now checks the bounded runtime-account state before
waiting for a composer. Syntax validation and the complete addon HOOT suite pass with that repair.
A follow-up browser attempt now fails explicitly at the runtime authentication boundary instead of
reporting an opaque localized-control timeout.
