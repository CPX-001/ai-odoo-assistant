## Failures found and repairs

1. This machine required isolated Playwright/Chromium and bytecode-cache paths plus its local Odoo,
   addon-path and provider executable configuration. Those were environment adaptations only.
2. The acceptance batch queried Playwright through `npx`, which could attempt package resolution and
   hang without network access. It now reads the installed package version through Node and
   `NODE_PATH`; no product assertion was changed.
3. The focused Odoo gate exposed loss of the explicit captured Odoo-language fallback when the user
   language was empty. The context builder now persists that empty fallback as `false`, preserving
   the bounded host-owned snapshot contract; the original assertion remains intact.
4. The browser continuity runner checked for the launcher immediately after reload and could wait on
   a panel it had never opened. It now waits for the web-client launcher before clicking it; the
   continuity, causality and cross-conversation assertions were not weakened.

After each repair the affected checks were repeated. The final complete batch reran all deterministic,
focused Odoo, full-addon and real-browser gates on the single clean checkpoint above.
