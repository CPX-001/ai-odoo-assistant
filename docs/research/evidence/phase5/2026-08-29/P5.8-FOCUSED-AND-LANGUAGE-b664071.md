## Repair made

The first focused Odoo execution reported two errors in the newly added provider lifecycle tests.
Both tests created a committed turn through an independent cursor but then attempted to mutate it
through the `TransactionCase` cursor. In this real Odoo environment that cursor treated the fixture
as missing after the independent live-event commit.

The tests now use the existing production-faithful pattern already exercised by the same module:
an independent worker cursor appends the lifecycle and an effective-user observer cursor reads the
independently committed public projection. The unchanged selector then passed 26/26.
