## Failures found and repaired

1. The local Odoo configuration routed logs to a file, so the batch could not parse final test
   totals even though the first full addon execution passed. Local validation arguments redirected
   the isolated test/server output to stdout; no product or test contract changed.
2. The browser runner counted model/autonomy options immediately after opening the selector. In
   real Chromium the portal menu can render one tick later, causing a false missing-option failure.
   Checkpoint `32e836e` now waits for the scoped visible menu before clicking while retaining all
   backend snapshot assertions.
3. A failed browser attempt left unresolved turns in the first disposable database, consuming the
   global scheduler capacity during a rerun. That contaminated database was discarded. The final
   combined batch ran from start to finish on a fresh disposable database and clean SHA.

No production runtime defect was found, and no test was weakened.
