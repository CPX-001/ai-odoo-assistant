# Historical task packets

Files in this directory are completed/superseded implementation packets from earlier repository milestones. They preserve acceptance criteria, security reasoning and implementation evidence for the commit/milestone in which they were written.

They are **not** a current backlog and their “next task”, gate, service, endpoint or milestone language must not be executed without revalidating current `main`.

For new work use current code/accepted ADRs, `docs/README.md`, `docs/CURRENT_STATE.md`, root `PLANS.md` and `../TASK_PACKET_TEMPLATE.md`.
