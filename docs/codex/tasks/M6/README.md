# Historical M6 task-packet index

Those principles remain relevant, but the implementation has since been consolidated into the embedded Odoo Capability Framework and current policy/execution services.

Do not interpret references here to the Assistant PostgreSQL database, rigid `ACTION` workflow, sidecar authorities or “next M7 milestone” as current requirements.
